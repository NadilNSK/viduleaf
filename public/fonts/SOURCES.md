# Locally hosted fonts

Downloaded from the Google Fonts source repository on 2026-11-11.
Both fonts use the SIL Open Font License 1.1. The original licence files are included here.

- DM Sans variable: https://github.com/google/fonts/tree/main/ofl/dmsans
- Libre Caslon Display: https://github.com/google/fonts/tree/main/ofl/librecaslondisplay

The browser loads these files from this project; no third-party font request is needed.
